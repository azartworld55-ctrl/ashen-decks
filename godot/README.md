# ASHEN DECKS — Godot

Новая версия ASHEN DECKS разрабатывается здесь отдельно от старой браузерной игры.

## Открыть проект

1. Установить Godot 4.4 или совместимую более новую версию Godot 4.
2. В Project Manager выбрать Import.
3. Указать файл `project.godot` в этой папке.
4. Запустить проект клавишей F6/F5 или кнопкой Run.

## Игровой цикл

- Стартовый экран на русском языке.
- Три последовательных боя в одном забеге.
- Колода, добор, сброс, энергия, блок, лечение и намерения врагов.
- Среди карт-наград есть «Пепельный импульс» (+1 энергия), «Шёпот колодца» (добор 2 карт), «Пепельная стена» (12 блока) и «Тихий обмен» (добор карты и возврат энергии). Запас энергии за ход ограничен 5, а размер руки — 5 карт.
- Три противника с возрастающей сложностью и разными циклами намерений: каждый этаж по-своему чередует атаку, подготовку и усиленный удар.
- Выбор одной из трёх случайных карт после первых двух побед.
- Выбор пути между этажами: костёр, тайник или алтарь.
- Случайная сюжетная встреча после каждого из первых двух этажей: три варианта решения с разными последствиями.
- Две постоянные реликвии: «Сердце углей» лечит в начале каждого боя, «Знак стража» даёт стартовый блок.
- Сохранение событий, реликвий и состояния забега; старые сохранения версии 2 принимаются.
- Перенос здоровья, золота и колоды между этажами.
- Просмотр всей текущей колоды во время боя.
- Локальное сохранение текущего забега и возможность продолжить после перезапуска.
- Завершение забега после финального босса.
- Адаптивная компоновка: на узких экранах карты идут в один столбец, а длинные экраны прокручиваются вертикально.
- Боевой статус отдельно показывает золото, стопку добора и сброса.

Проект остаётся в стадии разработки до полной проверки игрового баланса, мобильного управления и публикации. Все основные этапы забега уже соединены в единый цикл; боевые эффекты, награды, маршруты, события, реликвии и восстановление сохранения проверяются smoke-тестами.

## Проверки

GitHub Actions запускает headless-проверку проекта, тест игрового цикла и экспорт Web-сборки. Готовая сборка сохраняется как artifact workflow run. Пока она не публикуется на основном сайте. План публикации — отдельный адресный путь `/godot/`, чтобы не заменять старую игру.

## Release candidate

Эта ветка собирает цельный забег: три этажа, три боя, выбор наград и маршрутов, случайные встречи, постоянные реликвии, финального босса, поражение/победу и локальное продолжение. Публикация размещает новую версию в `/godot/`, сохраняя прежнюю браузерную игру в корне сайта.

Перед публикацией workflow повторно запускает тесты старой игры, проверку проекта Godot, полный smoke-набор и Web-экспорт. Если любой этап не проходит, Pages не обновляется.
